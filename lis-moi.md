# Minuit

Minuit est un jeu de blackjack en 3D, fait en Python avec Ursina. Le but est de se rapprocher de 21 sans le dépasser. Les jetons sont virtuels.

## Lancer le jeu

Cette version est prévue pour Windows 64 bits.

1. Si le projet est dans un fichier ZIP, extraire tout le contenu avant de commencer.
2. Ouvrir le dossier qui contient `minuit.py` et `Jouer.bat`.
3. Double-cliquer sur `Jouer.bat`.
4. Attendre que la fenêtre du jeu s'ouvre, puis cliquer sur **JOUER**.

Il n'y a rien à installer : Python et les bibliothèques sont déjà dans le dossier `python`. Il faut garder tous les dossiers du projet ensemble.

## Commencer une partie

Cliquer sur les jetons en bas pour choisir une mise, puis sur **DISTRIBUER**. Les actions se choisissent ensuite avec la souris.

Le bouton **APPRENDRE** affiche une aide pendant la partie. La touche **Échap** permet de mettre le jeu en pause.
